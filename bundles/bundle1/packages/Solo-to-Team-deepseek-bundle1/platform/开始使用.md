# DeepSeek Harness：采用项目协作 Skill

当前候选 `0.1.0-rc.5`，适用于 DeepSeek Harness（DSH），不是 DS Bot。它增补完整 MAS，保留原16席、6群、建队台、团队配置与原四技能。

## 先确定位置和同名旧件，再放文件

1. 选本次允许使用的真实项目根。已核 DSH 版本按会话工作目录发现项目；在 Git 仓库内，取最近 `.git` 祖先为项目根，不能把更深的子目录当作根。范围不清时先核实际项目，不猜路径。
2. 在该根的 `.dsh/skills/` 核对有无 `solo-to-team-deepseek`。同版且已核可用直接复用；不同版先把**这一技能目录**完整备份到本次允许的备份位置，记录原位置与版本，确认可恢复。已有适用替换授权就按它执行，没有替换依据先不写入。保留其他技能及旧的 `solo-to-team`，不覆盖整个 `.dsh`。
3. 只取本目录 [solo-to-team-deepseek-project.zip](solo-to-team-deepseek-project.zip)，先解到单独的临时文件夹；核到 `.dsh/skills/solo-to-team-deepseek/` 后，将**这个技能目录**放到选定项目根的 `.dsh/skills/`。`.dsh` 是隐藏文件夹；Mac 访达可用 Command＋Shift＋句点显示隐藏项。若解压工具另套一层文件夹，不把那一层也搬进去。

最终主文位置必须是 `项目根/.dsh/skills/solo-to-team-deepseek/SKILL.md`，同目录保留 `references/`、`assets/` 和 LICENSE。本目录另有 `solo-to-team-deepseek.zip`，它是通用技能目录包，**本项目采用步骤不用那份**。只处理本次技能目录，不移动项目其他文件。

## 调用与检查

在 DSH 打开这个项目，在 `/` 菜单选择 `solo-to-team-deepseek`，或输入 `/solo-to-team-deepseek`。让它实际读本版正文与需要的参考。旧会话的菜单可能缓存，以目标项目新会话的实际发现／加载为准；不声称所有会话立即更新。子任务可能有不同工作目录，分别核材料是否取得。

> 请使用 solo-to-team-deepseek 接手这份半成品，沿用已确认要求，安排真实制作和独立审核，把可打开的成果交回当前对话；先核项目、版本、执行者和本次已有授权。

该路径按项目采用，不等于账号全局安装。技能不注册永久16席或原生群；需要完整团队时另看[原 MAS 说明](../tools/team-16/SETUP.zh.md)。

## 放置或加载失败后

先停止在此项目调用本版，保留实际错误与已完成成果。如果此次是全新放入，可将确切的 `solo-to-team-deepseek` 目录移回本次备份／暂存位置；如果替换过旧版，用已保留的完整旧技能目录恢复原位置。只处理本次已识别目录，不删除其他技能，不将丢失旧件的覆盖称为可回滚。已发生的业务改动另按任务记录处理。

恢复后在目标项目新会话核菜单和实际读到的版本；旧会话可能仍留上下文／缓存，文件移出不等于所有运行中的会话立即忘记。无法确认时报告未恢复项，不改全局设置求通过。
