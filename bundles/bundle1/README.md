# 一人成队 · 四平台完整包

由人统筹的多智能体协作系统（MAS）。选自己使用的一个平台即可；每包都带一款平台协作Skill、四款完整基础Skills及必要配置、模板、示例和说明，不需要另找基础技能下载。

本次版本 **bundle.1 · 随 v0.2.0 提供**。平台原生载荷沿用adapter.5；此包装版本不是四端业务重测的成绩。

解压完整包后打开START-HERE。按本平台说明采用大Skill，再提供包内TASK-MATERIALS.zip作为本单资料，按任务读取基础Skills。外层完整ZIP和任务资料ZIP都不要当作平台“单技能上传”ZIP。四基础Skill完整随包，不等于自动注册成四个原生对象。

## 看整体，再按清单使用

- [配置使用清单总览](配置使用清单.md)：包内有什么，什么时候需要，怎样确认。
- [项目介绍PDF](pdf/一人成队_MAS工程与组织设计_v3_完整包与配置.pdf)：16页，原两张完整组织图保留，第15–16页是技能与配置概览。
- [本次变更](CHANGELOG.md)：哪些新增、哪些保持、尚未验证什么。
- [发布范围与已知限制](RELEASE-NOTES.md)：包装版本、原生证据与未验证范围。
- [维护与重建](source/README.md)：输入、脚本、指纹与四包空目录重建。

原MAS的带底稿、配置更新、案例与已有工具继续保留在原组合；这里新增四个可独立取得资料的平台包，不用它们替换掉整个MAS。新包自带建队台与接续工具，其他既有工具不冒称已经纳入四包。

平台账号、模型服务、真实执行者与权限由用户的既有环境提供；不承诺一个按钮自动建起16席六群。现役团队未安装本包。公开名称Open Master Bot对应原openmaus兼容标识，原生文件名与历史证据名称保留。
