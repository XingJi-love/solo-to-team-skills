# 配置使用清单 · 四平台总览

这是一份使用文件，不是额外安装任务。先选平台，再按该平台清单；不用同时安装四个平台，也不用把每份参考都注册成原生技能。

## 每个包必带的五款技能材料

| 平台 | 专用大Skill | 原生基线 |
|---|---|---|
| Grok Bot | solo-to-team-grok | design2-doc1 / adapter.5 |
| WorkBuddy | solo-to-team-workbuddy | 0.1.0-rc.5 |
| DeepSeek Harness | solo-to-team-deepseek | 0.1.0-rc.5 |
| Open Master Bot | solo-to-team-openmaus | 0.1.0-rc.5-om.4 |

以上每个包均附下列四款完整正文，位于foundation/skills/，同时带模板、示例和许可：

| 名称 | 中文名 | 用途 |
|---|---|---|
| `dispatch-accept-verify` | 派出去的活要收回来 | 派单、接单、接回、阶段与跟进登记 |
| `evidence-before-done` | 交活前要有证据 | 实际成果、同版核验、接受权限 |
| `beginner-ops-writing` | 新手操作说明 | 需要用户操作时，一次一步、写清可见结果 |
| `ops-case-notes` | 脱敏运营记录 | 查交接遗漏、经验与未证明的边界 |

## 技能之外的配置

| 配套内容 | 使用时机 | 用户要确认什么 |
|---|---|---|
| 16席岗位卡与角色路由 | 启用对应岗位或跨席交接前 | 谁委托、谁执行、谁审核、交给谁；不强制16席全开 |
| 六群通则与逐群规则 | 使用某个群时 | 读通则与适用群；群成员身份不扩大权限 |
| 团队配置JSON | 建队或改配置时 | 是可编辑底稿，不是四平台通用原生导入文件 |
| 离线建队台 | 改名、选岗、保存与导出 | 先保存底稿再导出；下载不等于原生建队 |
| 登记模板 | 有派收、退修和多步骤任务时 | 阶段与跟进事件分开；收到不是已验收 |
| 接续工具与断点记录 | 中断或换会话时 | 新接手者实际读到版本和未完项；不自动唤醒 |
| TASK-MATERIALS.zip | 向助手提供四基础Skills与配置 | 普通任务资料，不是单技能安装ZIP；读取范围按本单授权 |
| 安装、同名更新与退出说明 | 首次采用或换版本 | 只处理本次对象，保留旧件，按实际宿主核恢复 |
| 合成示例与首次检查 | 小任务试用 | 不能拿教学答案或历史记录冒充本次运行 |
| BUNDLE.json与SHA256SUMS | 核版本、排错、维护 | 文件一致不等于安装成功；区分包装与平台版本 |
| LICENSE与NOTICE | 使用和再分发 | 保留署名和许可，平台软件与私有材料不随本包授权 |

## 平台本身仍要具备的条件

可用账号与模型、获准工作目录、真实执行者、符合任务要求的审核者与收件渠道。这些不是配置文件能替用户开通的。简单任务不强加多席流程；缺实际独审条件就如实记录，不用一个对话扮演多人。

本次新包只完成文件级检查，不宣称五技能原生注册和组合业务在四端全部通过；安装、实际读取、真实协作与用户收件各自核实。PDF第15–16页是本清单的概览，实际步骤以对应包内文件为准。
