# 16 席，怎样组成一支队伍

[English](README.en.md) · [返回产品说明](../README.md)

这是离线维护者源码包中的六群编队说明。首发模板提供 **16 个岗位、6 个建议群**，默认含生活官，共 26 条建议入群关系。你可以按任务选用和调整；模板名单不代表已经在你的账号里建好了助手或群聊。

> 此源码归档不提供现役展示头像与编队展示图，因此本页采用文字说明。构建当前16席工具包不依赖这些私用图片；原展示材料另行保留。

现役展示头像由我们自己制作，仅供我们自己使用，不对外授权。下载工具包使用岗位示意图，不包含现役展示头像。

## 默认分组

| 群 | 建议成员 |
| --- | --- |
| 运营署 | 首席执行官、审核官、情报官、创意官、技术官、生产官 |
| 创作院 | 首席执行官、创意官、生产官、法商官、审核官 |
| 内务部 | 首席执行官、学习官、生活官 |
| 顾问团 | 首席执行官、审核官、情报官、情报顾问、审核助理 |
| 机务处 | 首席执行官、审核官、技术官、网络工程师、实施工程师 |
| 参谋室 | 首席执行官、分析专家 |

督查官和美术编辑仍在 16 席内，需要协作时由首席点对点联系。生活官的私人行程不进群。
