# Sixteen roles working as a team

[中文](README.md) · [Back to the product](../README.en.md)

This page describes the team grouping in the offline maintainer source archive. The first-release template offers **16 roles and six suggested groups**, with the daily-affairs role included by default: 26 suggested memberships in total. Choose and adapt them to your project. A template does not mean those assistants or chats already exist in your account.

> This source archive omits the current-team avatars and overview image, so this page uses text only. Building the current 16-role tool package does not require those private images; the original showcase materials are retained separately.

The current-team avatars were made by our own team and are for our own use only; no license is granted to others. The downloadable tool package uses illustrative role icons and does not include the current-team avatars.

## Default groups

| Group | Suggested members |
| --- | --- |
| Operations | Lead, reviewer, intelligence, creative, technology, production |
| Creation | Lead, creative, production, legal and business, reviewer |
| Internal affairs | Lead, learning, daily affairs |
| Advisers | Lead, reviewer, intelligence, intelligence adviser, review assistant |
| Engineering | Lead, reviewer, technology, network engineer, implementation engineer |
| Consultation | Lead, analysis specialist |

The inspection and art-editing roles are included in the 16-role roster but have no standing membership in these six groups. The lead contacts them when needed. Private itineraries stay out of group chats.
