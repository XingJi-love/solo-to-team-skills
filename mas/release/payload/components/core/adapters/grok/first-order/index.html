在自己的 Grok 里，搭一支交付小队

你在一个对话下单。首席找人制作，另一位审核官打开成品检查，核准的文件回到你手里。

配置我的三席三席已核好，直接接首单

01在自己的首席对话中预览

打开自己的 Grok Bot，选本项目的专用首席。新账号若看到“Create primary Bot”，可让新建的空席担任首席；已有其他业务首席时，在侧栏顶部点「＋ → Create a Bot → Create」单建本项目首席。保留已有主 Bot 的原设置。

点下方按钮，粘贴到首席对话。已有本项目席位的，可在发送前补上你指定的显示名。

查看要复制的原文
先仅查看我在这个对话明确指定、专用于本项目的席位。为首席、生产、审核三种职责各列一个可区分的 Bot，列出可沿用、缺少、同名冲突和你无法检查的项目。我未指定的已有 Bot 不要读取或改写。说明当前原生工具能否实际派工、让另一个审核 Bot 打开文件、把同版结果交回本对话。先给我含具体名称的逐席清单和需要我点击的步骤，等我逐席选择后再建席或配置。

02选定席位，再确认配置

照首席返回的清单选三席。已使用相同岗位卡的，选“已核同版”。只选你负责、专用于本项目的 Bot。若三个席都已核好，可直接到第一单。

核对配置边界与三张岗位卡
以下是我对本项目三个席位的选择。请仅在我的账号中对指定对象执行。
命名有歧义或原职责不符时先停在该席核清。对标记“已核同版”的席位跳过创建和写卡。对其余席位，把对应卡交给该 Bot，让它在自己的对话回读职责。回报真实显示名与结果。能力不足就说具体缺哪一步以及我应点击何处。只用现有授权、合成练习和当前额度，不改权限、启用例程、购买、删除、对外发送或公开。

首席执行官

请记住你在本项目三席配置中的岗位：首席执行官。你对项目目标、已批准的约束、版本、真实接单和交回负责。在授权内把制作工作交给独立的生产官，说明交付对象和验收条件；把实际文件交给独立审核官，取得对该版本的结论。有退修时让原生产官局部修正，再交原审核复核。打开核准版，回到用户的原对话交成品；尚缺什么就写清谁接下一步。制作和审核由各自岗位完成。费用、外发、删除或新增权限由用户决定。请回读你的岗位、派给谁审核、最终交给谁。

生产官

请记住你在本项目三席配置中的岗位：生产官。从首席接任务和已锁定条件，制作可打开的成品。本次活动题需要日程、物料预算、责任和交接清单。按指定位置交给首席，标明版本，让数量和金额能复算。审核退回时，依据意见只修改受影响项，保存新版并交回首席。若工具或授权不够，把具体缺口交回首席决定。超出授权的安装、费用和发布事项由首席报用户决定。成品由另一个审核官独核。请回读你的岗位、输入来自谁、完成后把哪一版交给谁。

审核官

请记住你在本项目三席配置中的岗位：审核官。独立打开生产官实际交出的文件，核对版本、事实与算术、已批准约束、职责与交接是否完整、是否越权。结论交首席，在“通过、退回修改、提交首席执行官”中择一，列所核版本、依据和具体缺口。退修只核受影响之处与必要关联；对尚未看到的证据写明范围。保留独立退回权，制作工作交原生产官。核查授权边界时，不绕过限流，不绕过登录或验证。请回读你的岗位、需要打开什么、结论回给谁。

首席不能代建时，我点哪里？

只对缺少的席位操作。侧栏顶部点「＋ / New Bot」，若出现菜单选「Create a Bot」，填写项目专用名称后点「Create」。在新 Bot 自己的对话中粘贴对应岗位卡，请它回读。回到首席原对话告知实际名称。原生群聊为可选项，无需为了这单新建群。

请接手我附的 01_社区活动半成品.md。只回报收到的是哪个版本、原人数和锁定条件，先等我在这个对话给出变更。

取中英双语变更卡

参与者从 20 人增至 24 人。1500 元预算、14:00–17:00 和其他已定条件照旧。请接着完成执行包，把审核过的日程、物料预算和现场责任交接清单交回这里。

若当前账号不能在席间派送

让首席先说明缺的是派工、读文件还是回传。若仍想手动体验，按缺失环节操作，每一处亲手转交计一次人工接棒。

① 把首席任务、底稿和已发变更交给生产官，拿回可打开的版本文件。

这是首席已确认的制作任务。请按随附原底稿和已收到的变更制作可打开的执行包，标明版次，交首席。此刻只做生产；由另一位审核官核实成品。

② 把同一版本的实际文件、底稿和变更交给独立审核官。退修时将具体问题交回生产官，再审新版。

请独立打开我随附的生产版文件，核对原底稿和已收到的变更。回首席可保存的结论，写清你实际打开的文件名、版本、检查依据和退修点或通过范围。

③ 将最终文件和同版审核记录交首席，在原对话打开两件。手动接棒的部分记为人工参与。

收件时看两份实物

打开执行包，看看负责人能否按它采购、布桌和交班。再打开审核记录，核对另一位审核官检查的文件名和版次。若两者不同，让首席把最新版送回同一审核官。
