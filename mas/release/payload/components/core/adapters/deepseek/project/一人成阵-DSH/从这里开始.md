# 用 DeepSeek Harness 跑第一单

这个项目让你从一份 20 人活动底稿开始，看生产官如何接手变更、审核官如何检查成品，最后在首席的原对话收件。适配依据为桌面版 0.2.1-rc.5。需要能正常对话的模型，以及对本项目的读写权限。运行会使用你所选模型的额度。

1. 打开 DeepSeek Harness，选工作区时只选本文件所在的 **一人成阵-DSH** 文件夹，然后打开一个新会话。项目技能随这个文件夹被发现。首次复制项目时请连同隐藏的 `.dsh` 文件夹一起保留。
2. 在输入框键入 `/`，从建议中选 **solo-to-team**。在同一条消息中接着写下面这句，再发送。
   
   > 请读取 inputs/01_社区活动半成品.md，只确认接单版本和已定事项。稍后我在这里发变更。
   
3. 等首席实际报出底稿版本，再把随本项目另给的《02_收到回执后发给首席.md》中的中文或英文变更发到**同一会话**。只发一次。若单独拿到项目目录，可使用你自己的具体人数变更，要求原定场地、预算和时段照旧。
4. 在原会话收件。你应能打开最终执行包和独立审核记录，核对两个文件指向同一版本；看看有没有写清用几桌、买多少、由谁交接。如果审核发生了退修，可对照旧稿和最终稿查看改了哪里。

**怎样认出三席真的在做事。** 原生实验团队开启时，首席会调用 `spawn_teammate`，你可在团队记录里看到两个具名队友。0.2.1-rc.5 的内置「智能体团队」可从「插件」页启用，设置影响当前配置；是否启用由你决定。已有独立子任务委派时也可以完成首单，结果会注明实际路径。如果系统只提供单会话，首席会回报缺少的能力。三张岗位卡放在项目里，只约定分工，不额外授予文件或系统权限。
