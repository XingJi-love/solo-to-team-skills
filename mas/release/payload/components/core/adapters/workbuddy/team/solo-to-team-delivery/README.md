# 一人成阵·项目交付

WorkBuddy 三席专家团候选，版本 0.1.0。首席接单、生产官制作、审核官独立打开同一版成品检查，最后由首席在原对话交件。

在账号已有权访问的专家团中打开「一人成阵·项目交付」，选择「召唤专家团」。给首席一个具体目标，或者附上一份未完成的文件，说：“先确认你收到的版本和已定条件，再把审核过的成品交回这里。”如果中途变更，回到同一对话告诉首席改哪一条。账号未出现该专家团时，请先核安装状态和访问范围。此次离线候选的制作不代表已经上架、注册或实跑。

## English

Open the **Solo to Team · Project Delivery** expert team in an authorized WorkBuddy account. Give its lead a goal or an unfinished file. Ask the lead to identify the starting version and constraints, have the production specialist create the deliverable, and return the independently reviewed version in the original conversation. Send changes in that same chat.

This package defines one lead, one production specialist and one independent reviewer. Availability, actual team permissions, usage charges and verified delivery depend on the host and account.
