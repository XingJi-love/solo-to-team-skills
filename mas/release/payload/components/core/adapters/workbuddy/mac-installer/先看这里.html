一人成阵

WorkBuddy 三席交付团队 · 0.1.0

你把任务交给首席，生产官制作成品，审核官打开同一版本检查。通过的文件从首席原对话交回。

在 Mac 上安装

  1. 用访达打开解压后的文件夹，双击一人成阵安装预览。第一屏会说明本机适配情况。看完可以直接关闭。
  2. 如显示可以登记，先保存 WorkBuddy 里正在做的事并自行退出。选登记本团，看清变更后再点确认登记。工具只处理这个版本的本地私有专家团。
  3. 重新打开 WorkBuddy，在专家 → 我的专家 → 我创建的找“一人成阵”。看见首席、生产、审核三席后，点召唤开始自己的任务。只预览或登记不会发起模型任务。

如果已经有同名团队

同一份 0.1.0 会直接跳过。若标识相同、来源或内容不同，安装器会保留现状并说明冲突。只有由这个安装器新增的团队，才会给出撤回本次新增。使用后改过的文件也会保留。

适配范围

内部候选。适配 macOS 12 及以上、WorkBuddy 5.9.3 和该版随附的官方注册脚本。支持 Intel 和 Apple 芯片。实际登记需要已有可用的 Python 3.8 或以上。预览会提示缺项，本工具不会替你下载或修改系统安全设置。

本地登记成功后，以客户端实际看见专家卡为准。官方注册脚本说明，离开真实的 WorkBuddy 创建会话，部分账户可能看不到新卡。若未出现，先停在这一步，勿重复登记。私有登记与后续使用模型的积分分开计算。
