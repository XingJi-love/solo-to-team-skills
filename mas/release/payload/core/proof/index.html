谁把一套备品算丢了？

活动从 20 人改成 24 人。负责制表的生产官算对了 1,464 元的预算，独立验件的审核官却退回了交接单。问题藏在散场时要填的一格里。

C7 行只管一套备品。当天发生了什么？

初稿 R1 · 审核退回

看起来少了 1 套

清单写死应交 1 套。第二桌已按计划领用，志愿者手里是 0 套。照表填写，就会多出一笔缺件。

实点 0 − 应交 1 = −1

刚好对上

备品没有动过，手里还有 1 套，表上应交 1 套。这个情况看不出初稿的问题。

实点 1 − 应交 1 = 0

修订版 R2 · 复核通过

实物和表格对上了

已领用应交 0 套，另填桌号和时间。下一位能分清这套备品去了哪里。

实点 0 − 应交 0 = 0

同样对上

未领用应交 1 套，实点 1 套。修订版保留了原来已经正确的情况。

实点 1 − 应交 1 = 0

两个选项用同一行规则推演。看到零库存时，还要核领用记录才能判定原因。

为什么审核官又看了一眼名牌？

同一份初稿还要求协调员移交 6 张备用名牌。这 6 张从签到开始就由现场志愿者保管。即使一张没少，协调员也交不出来。交回版在 A4 行写明实际保管人，划出本次移交范围。

负责派工和交件的首席把这两处退给原生产官。生产官另存 R2；审核官重新打开 R2 复核，首席把通过的文件和审核记录交回原对话。预算仍是 1,464 元。

这套团队规则做了什么

权限防呆
另一单把负责检查团队运转的督导所提的协调意见写成了用户决定。审核纠正归属，取得授权的更正送回原群，旧稿保留。
上下文隔离与降噪
活动单的两条意见直接回到原生产席，审核席收到的是对应修订版。团队也用机务处共享工程进度；节省了多少时间或 Token 尚无对照测量。
三权分立式质量护栏
审核官看成品，督查官查决定是否落实，督导办公室查机制。另一单里，修订已过审，原群里却只有旧稿。到目标群回看，才能验明更正是否送达。
