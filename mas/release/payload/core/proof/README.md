# 一张会把备品算丢的交接单 · The handoff sheet that lost a kit

**中文**　活动从 20 人改为 24 人。负责制表的生产官算对了 ¥1,464 的预算，独立验件的审核官却退回了初稿。打开清单的 C7 行：一套备品按计划发给某桌，散场时应交回几套？初稿填 1，交回版允许填 0，并登记领用桌号和时间。审核官重新打开修订版；负责最终交件的首席把成品和审核意见交回原对话。

**English**　Attendance changed from 20 to 24. The producer balanced the ¥1,464 budget, but a second agent reviewing the file returned it. Look at row C7. If a table uses the one spare kit as planned, how many kits should come back? The first version says one. The revision allows zero and records who took it and when. The reviewer reopened that version. The dispatch lead then delivered the pack and review to the original conversation.
