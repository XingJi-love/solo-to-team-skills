# 在 OpenMausBot 添加项目交付三席

适用版本为 **OpenMausBot 桌面版 0.1.148**，使用已就绪的本地个人工作区。这个部门包由一人成阵项目制作，包含一位首席、一位生产官和一位审核官。文件内有岗位说明和三张示意头像，群、例程、连接器均为零。

## 导入一次

1. 在侧栏点 **模板 → 导入 → 选择备份文件或团队文件**。选择同文件夹内的 [三席部门文件](team.openmaus.json)。看到预览后，核对名称「一人成阵 · 项目交付三席」和三位成员。
2. 先看现有部门列表。有同名试用部门就打开它核对；确认要新建才点 **添加团队**。重复添加会生成第二套，本机同名部门和席位会加上数字。
3. 导入后，在新部门逐席查看权限，**发第一条业务消息前，将三席的批准设置都设为“询问”**，只选择给练习用的文件夹和同部门接力所需的权限。包中的“询问”是建议，宿主实际沿用本机默认值，可能显示“完全访问”。确认已有可用模型，再开始练习；模型和费用沿用你自己的配置。若当前地点是公司共享云空间，请先切回本地个人工作区。

## 跑第一单

打开新部门里的 **一人成阵·首席**。附上一份练习初稿，或写下一个明确的小任务。例如：“请接这份初稿，先告诉我接的是哪一版。制作后，请另一席独立审核，最后在这个聊天把我能打开的文件交回来。”收到首席的收件回执后，可再补一条变更。

最后在同一聊天核对三样东西：实际可打开的文件、它的版本、审核官针对这个版本的结论。若退修，核对最新一版。需要你批准本地文件操作时，只批准本单需要的范围。导入时出现席位上限、权限或付费提示，可关闭预览，保留文件。

## English quick start

Use **OpenMausBot Desktop 0.1.148** in your local personal workspace. Open **Templates → Import → Choose a backup or team file**, choose the [department file](team.openmaus.json), then verify the department name and its three members. Choose **Add team** once. Importing again creates numbered copies.

Before sending a task, set each new bot’s approval level to **Ask**. The package can only suggest that setting. Check the actual selection, limit file access to a practice folder and use an already configured model. Start in the new department’s **一人成阵·首席** chat. Send a brief or a partial draft and ask the lead to return the deliverable there after production and independent review. Verify the file opens and its version matches the review.
