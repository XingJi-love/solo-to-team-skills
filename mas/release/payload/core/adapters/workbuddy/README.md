# WorkBuddy · 在 Mac 加入三席
先使用已有 WorkBuddy 5.9.3 和已配置账号。[阅读离线预览](preview.html)。准备添加时[获取 Mac 安装预览包](mac-installer.zip)，解压后打开“一人成阵安装预览”。先读它显示的团名、版本和三席，再选择是否登记。运行登记需要已有 Python 3.8 或更新版本。本候选使用本机签名，系统若拦截，可继续查看离线网页或选用另一个入口。

完成后，在 WorkBuddy“我的专家”查看项目交付三席，选择活动专用目录，再交[第一张卡](../../brief/01-intake.md)。已有同版无需重复登记。程序也可预览并撤回本次新增的登记。新账户能否显示团队卡以实际客户端为准。随附专家团是已用于首单的 0.1.0 原件，清单中 example.org 邮箱是格式占位。

## English
Open the [offline preview](preview.html) or get the [Mac preview and installer](mac-installer.zip). On an already configured WorkBuddy 5.9.3 Mac with Python 3.8+, unzip and open the preview app. Check the name, version and three roles before registering. Find the team in My Experts, then select a workspace and send the [starting brief](../../brief/01-intake.md). If macOS blocks the locally signed candidate, use the offline preview or choose another adapter.
