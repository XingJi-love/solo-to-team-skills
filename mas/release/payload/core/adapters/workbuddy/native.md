# WorkBuddy 自带入口 / Use the WorkBuddy client
在「我的专家」打开创建专家团，附件选择本目录的 [team.zip](team.zip)，请它预览该团的三个岗位、复用相同已登记版本，在你确认后按本机已有能力登记。该方式沿用原团队包。已有可用账号，且本机能运行官方登记脚本（需 Python）时才适用。

据团队本机观察（核验记录留在团队侧，未放入本包），官方 5.9.3 的 ZIP 预览能读出三席，官方校验和登记脚本能在空资料库登记原 10 件。此次没有普通账户从附件走完界面的记录。若以后持有团队所有者生成的 WorkBuddy 官方分享链接，可在 WorkBuddy 自带接收页预览并按其安全检查选择是否加入。本包没有提供分享链接。Windows 新用户的端到端导入还未实测。

In My Experts, open the expert-team creator, attach [team.zip](team.zip), and request a preview before registering. In the team’s local test, whose records are outside this package, the original package was accepted by the bundled 5.9.3 preview and registration code in an isolated store. The registration scripts need an available Python installation. A new account completing this path in the native UI is unverified. A separate official WorkBuddy team share link can use the native receive and safety-check workflow if the owner creates one.
