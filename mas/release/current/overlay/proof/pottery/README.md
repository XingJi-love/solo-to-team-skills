# 四张初稿变成三张展签

[打开三页印样](labels.pdf) · [打开首席交回的 HTML](labels.html) · [English](README.en.md)

展览负责人有一份登记表和一份抄到一半的排印初稿。现场是虚构的，本机操作者记录，制件在 Mac 上的 DeepSeek Harness 里实际运行。操作者先只交两份文件，首席执行官读出登记表中有四件，发现《窑心》的材料和年份抄错，并按委托停在收件阶段。[登记表](inputs/register.csv) · [排印初稿](inputs/draft.md)

负责人随后在原会话撤下 Q03，把顺序改成 Q04、Q01、Q02。生产官做出展签，审核官打开对应的 HTML 和改动清单，核对原件并实际打印成 PDF。首席执行官在同一会话交回 HTML、工作人员清单和独立审核记录。原始两份底稿的内容保持一致。[另发的变更](change.txt) · [工作人员清单原件](change-log.md)
