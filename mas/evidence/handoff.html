两处修订的证据 · Two changes you can inspect

交接单 / The handoff sheet

以下摘录均来自同一次 WorkBuddy 活动执行包的物料交接单。R1 是审核退回的初稿，R2 是首席交回的修订版。中文引号内取自表格，英文为本页译文。

Both revisions come from the materials handoff sheet in one WorkBuddy activity pack. R1 was returned for changes. The lead delivered R2. Quoted Chinese is transcribed from the cells. English is a translation.

原表位置 / RowR1R2
C7：未使用的备用材料 / Unused reserve kit“1 套” / 1 kit.“1 套（未动用）／0 套（已动用，注明桌号与时间）” / 1 if unused; 0 if used. Record table and time.
A4：名牌备品 / Spare badges“6 张” / 6 badges on the coordinator's handoff list.应交数量栏“—”。备注“现场志愿者自 14:00 起保管，随签到台，不纳入本次协调员→志愿者移交”。 / No transfer quantity. The on-site volunteer keeps the badges at check-in from 14:00. Excluded from this coordinator-to-volunteer handoff.

如何复算。 假设备品只有 1 套，已按计划领用 1 套，实点为 0。R1 的实点减应交为 0 − 1 = −1。R2 为 0 − 0 = 0，另需填桌号和时间。若没有领用，两版均为 1 − 1 = 0。缺领用记录时应先查清，不能把零库存直接认作正常领用。A4 则检验另一件事：一件东西可以确实在场，却根本不属于这两个人本次要清点移交的物品。

Reproduce it. Start with one spare. If a table legitimately takes it, the physical count is zero. R1 yields 0 − 1 = −1. R2 yields 0 − 0 = 0 and asks for the table and time. If the spare stays unused, both give 1 − 1 = 0. A zero count alone does not establish authorized use. A4 tests custody: an item can be present at the venue and still fall outside this particular transfer.

上下文隔离与降噪 / Context routing组织设计设有工程工作群共享进度，技术、实施和审核席可在同处核对，细节由对应席位处理。活动单中，首席把两条退修意见交给原生产席，再让审核席核同一修订版。前者是组织设计，后者是已发生的一次定向交接。 / The engineering group gives technical, implementation and review seats a shared progress view. Each seat handles its own detail. In the activity run, the lead routed the two findings to the original producer and the revision back to review. The group is a design example; the targeted handoff occurred in this run. Token and latency effects were not measured.
三权分立式质量护栏 / Three scopes of quality oversight一席核成品，一席查决定是否落实，另由团队外的复核者检查协作方式。活动单可核第一项。另据团队自述，一次修订审核通过后，目的群仍只有旧稿；复核者回看后发现差异，后来核到更正与旧稿并存。该单原始记录在团队侧。 / One role reviews the artifact, another checks implementation, and an outside reviewer examines how the team works. The activity demonstrates artifact review. In a separate team-reported case, the target group still held an old post after approval; a subsequent check found the correction beside it. The underlying record is held by the team.

一次运行能提供可读的前后差异。它不能给出长期成功率、节省多少时间或新用户安装成功率。

This run supplies a concrete before-and-after comparison. Long-term reliability, time savings and first-time installation rates were not measured.
